# Private base source host

U3d introduces an internal Core host, not an enabled production base provider. `BaseHost` requires a trusted native caller's exact version and file SHA-256 inventory. The package uses the existing authoring schema 2, `simoder.authoring`, gameplay kind, `simoder.base`, Luau `scripts/init.luau`, 8 MiB and 2 ms. There is no manifest role, downloader, alternate cache or extra manifest format.

The host copies its pin, captures at most 64 files and 4 MiB, validates portable canonical names, plain paths, the complete bounded scripts tree and all hashes before compiling any source. Compilation consumes those captured immutable bytes through the existing pinned Luau compiler. Concurrent later disk mutation cannot substitute compiled bytes. The source tree may include non-executable repository documentation outside `scripts/`; those files are neither loaded nor trusted. All executable files must be pinned `.luau` sources. Native filesystem reads open the final file without following a reparse point, disallow concurrent write/delete sharing and allocate only after checking its handle size.

`InspectSourceManifest` is the shared pure metadata/script parser used by normal authoring inspection and the private host. Additional strict base checks reject resources, patches, symbols, services and unknown root fields. Ordinary source loading and direct `ScriptRuntime` construction reject the reserved base ID. Only the native host can construct the private role. The bootstrap uses the existing one script lane, generation registry, allocator and aggregate 128 MiB reservation. It has no PROP table, resource aliases, game authority, provider registration or readiness publication. A running VM is execution evidence only.

One host owns the bootstrap slot. Verification, compilation and initialization failures release it. Retirement and close complete on the shared script lane before releasing singleton ownership. A source package with missing required critical services fails initialization; a synthetic graph may exercise infrastructure but cannot establish production readiness. Real critical services and the private readiness lease remain U3e scope.

Diagnostics remain local bounded lifecycle evidence and mod-owned error text. This host adds no crash handler, memory dump, upload or automatic diagnostic redaction claim. Beta crash-format and helper-process decisions remain separate discovery.
